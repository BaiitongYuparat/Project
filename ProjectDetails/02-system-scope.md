# สรุปขอบเขตระบบ Virtual Try-On

## ภาพรวมระบบ
แพลตฟอร์ม **Virtual Try-On** (ลองสวมเสื้อผ้าเสมือนจริง) ที่ใช้ AI วิเคราะห์รูปร่างและแนะนำเสื้อผ้า พร้อมเชื่อมไปซื้อสินค้ากับร้านค้าต้นทาง

---

## 1. ระบบสมาชิก
- สมัคร/ล็อกอินได้ทั้งอีเมลและ Google (OAuth), ยืนยันตัวตนผ่านอีเมล/OTP
- แก้ไขข้อมูลส่วนตัว, ลืมรหัสผ่าน/รีเซ็ตรหัสผ่าน
- กรอกข้อมูลสรีระเบื้องต้น (เอว / สะโพก / อก / ส่วนสูง) เพื่อใช้แนะนำเสื้อผ้า
- มีประวัติการลองสวมใส่ย้อนหลัง (Try-On History)
- มี Onboarding พาผู้ใช้ใหม่ทำความรู้จักฟีเจอร์หลักครั้งแรกที่เข้าใช้งาน

### การจัดการความเป็นส่วนตัว
- หน้ายินยอมการใช้ภาพร่างกาย (Consent) **แยกจากข้อตกลงการใช้งานทั่วไป** เนื่องจากเป็นข้อมูลอ่อนไหว
- ผู้ใช้มีสิทธิ์ขอลบข้อมูลส่วนตัวและภาพทั้งหมดออกจากระบบ

---

## 2. ระบบ Admin
- **Dashboard** สรุปข้อมูลรอบด้าน:
  - จำนวนผู้เข้าใช้งาน
  - สินค้าที่ถูกใจมากที่สุด (แยกตาม category)
  - สินค้าที่ถูกกดลิงก์ไปซื้อมากที่สุด
  - ยอด Products ทั้งหมด
  - จำนวนครั้ง Try-On สำเร็จ/ล้มเหลว
  - เสื้อผ้าที่ user try-on มากที่สุด
  - จำนวน report (pending / resolved)
  - จำนวนครั้งเรียก AI API และ AI cost
  - ยอดสมัครและรายได้แต่ละแพ็กเกจ
- ระงับ/ยกเลิกบัญชีผู้ใช้ที่ผิดกฎ (เช่น อัปโหลดภาพไม่เหมาะสม)
- ตรวจสอบ Log การ Sync ข้อมูลร้านค้า (Sync Error) + แจ้งเตือนอัตโนมัติเมื่อเกินเกณฑ์ที่กำหนด
- ตั้งค่าการเชื่อม API ร้านค้า
- ดูรายชื่อผู้ใช้งานทั้งหมด พร้อมค้นหา/กรอง (วันสมัคร / สถานะ / จำนวนครั้งที่ใช้งาน)
- จัดการสิทธิ์การเข้าถึงทีมงานร้านค้า
- จัดการ report / flag เนื้อหาที่ผู้ใช้แจ้งเข้ามา
- แก้ไข Prompt ของ AI ได้ พร้อมประวัติการแก้ไข (ใครแก้/เมื่อไหร่/แก้อะไร) และปุ่ม **Rollback** กลับเวอร์ชันก่อนหน้า

---

## 3. ระบบอัปโหลดภาพผู้ใช้
- อัปโหลดภาพ 4 มุม (หน้าตรง / ข้างซ้าย / ข้างขวา / เต็มตัว)
- ถ่ายภาพสดผ่านกล้อง (กรณีไม่มีรูปภาพที่ใช้ในตอนนั้น)
- ตรวจสอบคุณภาพภาพอัตโนมัติ (ความชัด / มุมมอง / แสง)
- อัปโหลดเสื้อผ้าที่ตัวเองมีเพื่อสวมใส่ในการถ่าย
- **ลบภาพต้นฉบับอัตโนมัติ** ตามนโยบายการเก็บข้อมูล (Data Retention Policy)
- แสดงคำแนะนำการถ่ายภาพ (พื้นหลังเรียบ ท่ายืนตรง แสงเพียงพอ) ก่อนถ่าย/อัปโหลด

---

## 4. ระบบแนะนำเสื้อผ้า
- **Body-type AI**: คำนวณสรีระจากข้อมูลที่กรอก วิเคราะห์รูปร่าง และแนะนำเสื้อผ้าที่เหมาะสม (ฟีเจอร์มีค่าใช้จ่ายเพิ่มเติม)
- **Mix & Match**: แนะนำการจับคู่เสื้อผ้าจากสินค้าที่มีในระบบ
- แนะนำชุดตามโอกาส เช่น งานแต่ง งานสัมภาษณ์ ออกกำลังกาย
- ค้นหาสินค้าด้วยภาพ

---

## 5. ระบบจำลองการสวมใส่ (Virtual Try-On)
- มี Model จำลองให้เลือกใช้งาน กรณีไม่ต้องการอัปโหลดภาพตนเอง
- รองรับการมิกซ์หลายชิ้น (เสื้อ + กางเกง/กระโปรง) แสดงผลในภาพเดียวกัน
- เปรียบเทียบผลลัพธ์ก่อน-หลังใส่
- บันทึก/แชร์ผลลัพธ์ได้
- มีกระบวนการสำรอง (Fallback) เมื่อ AI ประมวลผลไม่สำเร็จ เช่น ภาพมุมไม่เหมาะสม หรือลวดลายซับซ้อนเกินไป

---

## 6. ระบบตะกร้า / เชื่อมไปหน้าซื้อสินค้า
- เชื่อมต่อ API ตะกร้าสินค้าไปยังหน้าชำระเงินของร้านค้าต้นทาง (ไม่มีระบบชำระเงินของตัวเอง)

---

## 7. ระบบสมาชิกแบบชำระเงิน (Subscription/Billing)
- จัดการแพ็กเกจและการชำระเงินสำหรับฟีเจอร์ที่มีค่าใช้จ่ายเพิ่มเติม
- Tier ต่าง ๆ:
  - **Free**: Try-On พื้นฐาน
  - **Premium**: Body-type AI + Try-On ไม่จำกัด
- มีระบบ Trial ทดลองใช้ฟรีก่อนสมัคร

---

## หมายเหตุสำคัญเกี่ยวกับขอบเขต

### 1. ระบบ Virtual Try-On
- ประยุกต์ใช้ Pretrained Model ที่มีอยู่แล้ว (เช่น IDM-VTON, OOTDiffusion, CatVTON) มาเชื่อมต่อหรือปรับแต่ง (Fine-tune) — **ไม่ได้พัฒนาโมเดล AI ขึ้นใหม่ทั้งหมด**
- เน้นพัฒนา Pipeline การประมวลผลภาพ การเชื่อมต่อ API และการแสดงผลลัพธ์ในระบบ

### 2. ขอบเขตด้านข้อมูลและความเป็นส่วนตัว
- ไม่เก็บภาพต้นฉบับของผู้ใช้ไว้ถาวรโดยไม่ได้รับความยินยอม
- ไม่นำภาพผู้ใช้ไปใช้ฝึก (train) โมเดลใหม่โดยไม่แจ้งล่วงหน้า
- ความแม่นยำของ Body-type AI อ้างอิงจากข้อมูลสรีระที่กรอกเอง ไม่ใช่การวัดจากภาพ 3D จริง จึงมีค่าความคลาดเคลื่อนที่ยอมรับได้ ต้องระบุไว้ชัดเจนใน UI
