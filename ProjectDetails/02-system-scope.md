# ขอบเขตของระบบ

รายละเอียด

## 1. ระบบสมาชิก (Membership System)
### 1.1 ฟังก์ชันหลัก
- สมัครสมาชิกด้วยอีเมลและกรอกข้อมูลส่วนตัว
- เข้าสู่ระบบด้วยบัญชี Google (OAuth)
- ยืนยันตัวตนผ่านอีเมล/OTP หลังสมัครสมาชิก
- แก้ไขข้อมูลส่วนตัว
- ลืมรหัสผ่านและรีเซ็ตรหัสผ่าน (Reset Password)
- กรอกข้อมูลสรีระเบื้องต้น(เอว / สะโพก / อก / ส่วนสูง)
- ประวัติการลองสวมใส่ย้อนหลัง (Try-On History)
- พาผู้ใช้ใหม่ทำความรู้จักฟีเจอร์หลักครั้งแรกที่เข้าใช้งาน (ถ่ายภาพยังไง, Try-On ยังไง)
### 1.2 การจัดการความเป็นส่วนตัว
- หน้ายินยอมการใช้ภาพร่างกาย (Consent) **แยกจากข้อตกลงการใช้งานทั่วไป เนื่องจากเป็นข้อมูลอ่อนไหว
- สิทธิ์ในการขอลบข้อมูลส่วนตัวและภาพทั้งหมดออกจากระบบ

## 2. ระบบAdmin
- Dashbord (แสดงจำนวนผู้เข้าใช้งาน / สินค้าที่ user กดถูกใจมากที่สุด (แยกตาม category) / สินค้าที่ user กดลิงก์ไปซื้อมากที่สุด (สินค้ายอดนิยม) / ยอด Products ทั้งหมด / จำนวนครั้งที่ Try on สำเร็จ และ ล้มเหลว / เสื้อผ้าที่ user try on มากที่สุด / จำนวน report (แยกตามสถานะ pending / resolved) / AI Api ถูกเรียกกี่ครั้ง / AI cost / แต่ละแพคเกจมีคนสมัครกี่คน รวมรายได้ต่อแพคเกจ)
- ระงับ/ยกเลิกบัญชีผู้ใช้ที่ผิดกฎ (อัปโหลดภาพไม่เหมาะสม )
- ตัวสอบ Log การ Sync ข้อมูลร้านค้า (Sync Error)
- ระบบแจ้งเตือนอัตโนมัติเมื่อ Sync Error เกินเกณฑ์ที่กำหนด
- ตั้งค่าการเชื่อม API ร้านค้า
- ดูชื่อผู้ใช้งานทั้งหมดในระบบ พร้อมค้นหา/กรอง (วันสมัคร / สถานะ / จำนวนครั้งที่ใช้งาน)
- จัดการสิทธิ์การเข้าถึงทีมงานร้านค้า
- จัดการ report / flag เนื้อหาที่ผู้ใช้อื่นแจ้งเข้ามา
- แก้ promt ai ได้ สั่ง ai ได้ และ ประวัติการแก้ไข (ใครแก้ เมื่อไหร่ แก้อะไร) และปุ่ม Rollback กลับเวอร์ชันก่อนหน้า หากแก้แล้วผลลัพธ์แย่ลง 

## 3. ระบบอัพโหลดภาพผู้ใช้
- อัพโหลดภาพ (หน้าตรง / หันข้างซ้าย / หันข้างขวา / เต็มตัว)
- ถ่ายภาพสดผ่านกล้อง (กรณีไม่มีรูปภาพที่ใช้ในตอนนั้น)
- ตรวจสอบคุณภาพอัตโนมัติ (ภาพไม่ชัด / มุมมอง / แสง)
- อัพโหลดเสื้อผ้าที่ตัวเองมี (สวมใส่ในการถ่าย)
- ลบภาพต้นฉบับอัตโนมัติตามนโยบายการเก็บข้อมูล (Data Retention Policy)
- แสดงคำแนะนำการถ่ายภาพ (พื้นหลังเรียบ ท่ายืนตรง แสงเพียงพอ) ก่อนถ่ายหรืออัปโหลด

## 4. ระบบแนะนำเสื้อผ้า
- Body-type AI คำนวณสรีระจากข้อมูลที่กรอกเบื้องต้น วิเคราะห์รูปร่าง และแนะนำเสื้อผ้าที่เหมาะสม (ฟีเจอร์นี้มีค่าใช้จ่ายเพิ่มเติม)
- Mix & Match แนะนำการจับคู่เสื้อผ้าจากสินค้าที่มีในระบบ
- แนะนำชุดตามโอกาส เช่น งานแต่ง งานสัมภาษณ์ ออกกำลังกาย
- ค้นหาสินค้าด้วยภาพ

## 5. ระบบจำลองการสวมใส่ Virtual Try-On 
- มี Model จำลองให้เลือกใช้งาน กรณีผู้ใช้ไม่ต้องการอัปโหลดภาพตนเอง
- รองรับการมิกซ์หลายชิ้น (เสื้อ + กางเกง/กระโปรง) แสดงผลในภาพเดียวกัน
- เปรียบเทียบผลลัพธ์หลังใส่และก่อนใส่
- บันทึก/แชร์ผลลัพธ์
- มีกระบวนการสำรอง (Fallback) เมื่อ AI ประมวลผลไม่สำเร็จ เช่น ภาพมุมไม่เหมาะสม หรือลวดลายเสื้อผ้าซับซ้อนเกินไป

## ระบบตะกร้า/เชื่อมไปหน้าซื้อสินค้า
- เชื่อมต่อ API ตะกร้าสินค้าไปยังหน้าชำระเงินของร้านค้าต้นทาง


## ระบบสมาชิกแบบชำระเงิน (Subscription/Billing)
- จัดการแพ็กเกจและการชำระเงินสำหรับฟีเจอร์ที่มีค่าใช้จ่ายเพิ่มเติม
- Tier ต่าง ๆ เช่น Free (Try-On พื้นฐาน), Premium (Body-type AI, Try-On ไม่จำกัด)
- ระบบ Trial ทดลองใช้ฟรีก่อนสมัคร


## **หมายเหตุสำคัญเกี่ยวกับขอบเขต
1. ระบบ Virtual Try-On 
- ประยุกต์ใช้ Pretrained Model ที่มีอยู่แล้ว (เช่น IDM-VTON, OOTDiffusion, CatVTON) มาเชื่อมต่อหรือปรับแต่ง (Fine-tune) ไม่ได้พัฒนาโมเดล AI ขึ้นใหม่ทั้งหมด
- เน้นการพัฒนา Pipeline การประมวลผลภาพ การเชื่อมต่อ API และการนำผลลัพธ์มาแสดงผลในระบบ

2. ขอบเขตด้านข้อมูลและความเป็นส่วนตัว
- ระบบไม่เก็บภาพต้นฉบับของผู้ใช้ไว้ถาวรโดยไม่ได้รับความยินยอม
- ไม่มีการนำภาพผู้ใช้ไปใช้ฝึก (train) โมเดลใหม่โดยไม่แจ้งล่วงหน้า
- ขอบเขตความแม่นยำของ Body-type AI อ้างอิงจากข้อมูลสรีระที่กรอกเอง ไม่ใช่การวัดจากภาพ 3D จริง จึงมีค่าความคลาดเคลื่อนที่ยอมรับได้ระบุไว้ชัดเจนใน UI
